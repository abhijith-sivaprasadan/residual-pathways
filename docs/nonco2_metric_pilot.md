# Gas reporting and conditional N2O metric comparison

Actual teaching-source analysis examines exact-name World CO2, CH4, N2O and reported Kyoto Gases series in 2050 and stratifies coverage by climate-vetted C1–C8. It does NOT compute aggregate gas CO2-equivalent across all gases.

For original reported N2O mass (kt N2O/year), convert the class average to Mt N2O/year by dividing by 1000, then apply the named IPCC AR6 WGI GWP100 original 2021 value 273 or 2025 erratum 267. The difference reflects a **metric reference change on identical physical emissions**, not a physical change or scenario result. The average is over reporting scenarios only; no non-reporting scenarios are filled as zero, and the mean is not a global emissions total or independent-model uncertainty estimate.

CH4 is deliberately not converted because source aggregated methane does not identify fossil versus non-fossil methane and corresponding AR6 coefficients. Already reported Kyoto Gases/CO2e is not converted again; the original metric and composition are unreviewed. Records with mismatched N2O unit fail closed.

The teaching dataset and separately republished metadata are not a canonical authenticated official AR6 v1.1 download. Source hashes and result reproducibility are checked through GitHub Actions. Use project v3 workpackage A-WP7 and IPCC AR6 WGI Chapter 7 plus the errata for original and corrected values. The gas source semantics and aggregate inventory remain conditional on independent model documentation review.
